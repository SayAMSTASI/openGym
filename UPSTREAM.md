# Source provenance

This is a modified, non-commercial openGym distribution based on
https://github.com/DuarteSantos8/openGym at commit
`e348fc17` (release 1.4.1 development snapshot).

Modifications dated 2026-10-20: Russian localization, local nutrition and supplement
tracking, Open Food Facts barcode search, per-profile read-only MCP/API access,
one-time owner initialization, invitation registration and administrator transfer.

The initial public commit is a clean source snapshot; local runtime data and local
development history are intentionally excluded. Copyright notices, LICENSE and
NOTICE.md from the original project remain applicable. Exercise media retain their
separate license limitations; see NOTICE.md before commercial use or extracting them.
